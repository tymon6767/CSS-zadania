Zadanie 2: Definicja CSS

CSS (Cascading Style Sheets) – Kaskadowe Arkusze Stylów to specjalny język stworzony w celu elastycznego zarządzania sposobem formatowania (wyglądem) elementów znajdujących się na stronach WWW.

Zadanie 3: Cechy modyfikowania formatowania w HTML oraz CSS

Cecha w HTML w CSS
Organizacja kodu Bardzo żmudna – atrybuty porozrzucane w kodzie, mieszają się ze strukturą Rozdzielenie struktury i prezentacji – wszystkie style w jednym miejscu

Nowe możliwości CSS:

  1. Przestarzałe atrybuty HTML są wycofywane na rzecz CSS
  2. Bardziej przejrzysty i krótszy kod
  3. Łatwe zarządzanie wieloma dokumentami dzięki zewnętrznym arkuszom
  4. Użycie klas i selektorów – duża oszczędność kodu
  5. Różnorodne jednostki miar i sposoby definiowania kolorów
  6. Więcej opcji formatowania tekstu (9 stopni pogrubienia itp.)
  7. Efekty graficzne i filtry
  8. Zaawansowane formatowanie przy drukowaniu

Wady CSS:

  1. Złożona specyfikacja, nie toleruje błędów składniowych
  2. Brak sygnalizacji błędów
  3. Różna obsługa przez różne przeglądarki

Zadanie 4: Sposoby podłączania stylów do strony

1. Zewnętrzny arkusz stylów (zalecany)

<link rel="stylesheet" type="text/css" href="style.css">

2. Styl liniowy (inline)

<p style="color: red; font-size: 20px;">Tekst</p>

3. Wewnętrzny arkusz stylów

<style>
    p { color: blue; }
</style>

4. Import arkusza stylów

<style>
    @import url("style.css");
</style>

5. Alternatywne arkusze stylów

<link rel="alternate stylesheet" title="Nazwa" href="styl2.css">

Kaskadowość stylów i priorytety

Kolejność ważności (od najsilniejszego):

  1. Styl liniowy (inline)
  2. !important
  3. Styl wewnętrzny
  4. Styl zewnętrzny
  5. Import
  6. Domyślne style przeglądarki

Jednostki miar

  • Bezwzględne: px, cm, mm, in, pt, pc
  • Względne: em, rem, %, vw, vh, vmin, vmax

Sposoby określania kolorów

  • Nazwa koloru: red
  • HEX: #FF0000
  • RGB: rgb(255, 0, 0)
  • Procentowo: rgb(100%, 0%, 0%)

Rodzaje selektorów

  • Prosty (np. p, h1)
  • Uniwersalny (*)
  • Potomka (div p)
  • Dziecka (div > p)
  • Klasy (.nazwa)
  • ID (#nazwa)
  • Pseudoklasy i pseudoelementy
