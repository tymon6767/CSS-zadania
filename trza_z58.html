Pseudoklasy w CSS

1. Co to są pseudoklasy?
Pseudoklasy to specjalne słowa w CSS, które pozwalają formatować elementy w zależności od ich stanu (np. czy link był kliknięty, czy myszka jest nad elementem).

2. Bardzo ważna rzecz:
Między selektorem a pseudoklasą zawsze musi być dwukropek :

3. Najważniejsze pseudoklasy

A:link – link jeszcze nie odwiedzony
A:visited – link już odwiedzony
A:hover – kursor myszki jest nad linkiem
A:active – link jest właśnie klikany
A:focus – element ma fokus (np. po naciśnięciu Tab)
:first-child – pierwsze dziecko elementu

4. Zastosowanie pseudoklasy :active

• uzupełnienie definicji odnośników
• poprawa czytelności formularzy

5. Przykłady kodu

Przykład 1:

A:link { color: blue; }
A:visited { color: purple; }

Przykład 2:

A:hover { color: red; text-decoration: underline; }
A:active { color: darkred; }

Przykład 3:

A { color: navy; }
A:link { color: blue; }
A:visited { color: purple; }
A:hover { color: red; }
A:active { color: darkred; }
