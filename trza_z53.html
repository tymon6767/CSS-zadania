Zadanie 53 – Inspektor Elements oraz Pasek dewelopera (DevTools)

1. Do czego służy Pasek dewelopera (Web Developer Tools / DevTools)?

Pasek dewelopera (DevTools) to wbudowane w przeglądarkę zaawansowane narzędzie diagnostyczne i developerskie. Jest gotowy do użycia zaraz po zainstalowaniu przeglądarki (Chrome, Firefox, Edge itp.).

Zawiera wiele zakładek, m.in.:

  • Elements / Inspector – edycja HTML i CSS na żywo
  • Console – błędy i logi JavaScript
  • Network – ruch sieciowy, ładowanie zasobów
  • Sources – debugowanie kodu JavaScript
  • Performance – analiza wydajności
  • Application / Storage – cookies, localStorage, service workers itp.

2. Do czego służy Inspektor Elements?

Inspektor Elements (zakładka **Elements** w Chrome / **Inspektor** w Firefox) to podstawowe narzędzie do:

  • Podglądu struktury HTML/DOM strony
  • Edycji HTML i CSS „na żywo” (zmiany widoczne natychmiast)
  • Sprawdzania zastosowanych stylów (kolory, marginesy, fonty, kaskada)
  • Zaznaczania i badania konkretnych elementów na stronie

Skróty otwierania:

F12                  → najszybszy sposób
Ctrl + Shift + I     → otwarcie DevTools

Przykład użycia (zrzut ekranu w szkielecie)
